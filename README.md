# hamora

Aplikasi mobile **rating movie** — project kelompok.

## Fitur

- Lihat daftar film
- Beri rating & ulasan film
- Firebase sebagai backend

## Tech Stack

- Flutter / Dart
- Firebase

## Cara Menjalankan

```bash
flutter pub get
flutter run
```
